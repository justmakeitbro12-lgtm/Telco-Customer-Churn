This project is useful for businesses to understand which features influence customer churn. I created an interactive dashboard that allows users to easily access and explore the results through a shared link(https://shorturl.at/Nc6dO).

The analysis showed that features such as Total Charges, Monthly Charges, Tenure, Payment Method, Online Security, and Tech Support have a strong impact on customer churn. These factors help identify customers who are more likely to leave the company.

The project can assist companies in predicting customer churn and understanding the key factors that contribute to it. This enables businesses to improve customer retention strategies and reduce the risk of losing valuable customers.
